Google Homepage (1998)

A recreation of Google's original homepage from 1998, bringing back the simple and classic design of the early Google search engine.

📖 About the Project

This project recreates the appearance of Google's original homepage from 1998. It represents the early days of Google, when its homepage had a simple layout, a clean white background, and a basic search interface.

The main goal is to preserve the vintage look and feel of the original Google homepage while making it functional using modern web technologies.

✨ Features

- Classic Google-inspired 1998 design.
- Simple and clean search interface.
- Search functionality.
- Vintage layout and styling.
- Search results displayed below the search bar.
- Responsive layout for different screen sizes.

🛠️ Technologies Used

- HTML5 – Creates the webpage structure.
- CSS3 – Handles the design, layout, and styling.
- JavaScript – Adds interactive features and functionality.
- Google Programmable Search Engine – Provides search functionality.

🎯 Project Objective

The objective of this project is to recreate an old Google homepage and explore how early web design can be recreated using modern web development technologies.

It also serves as a learning project for understanding HTML, CSS, and JavaScript.
